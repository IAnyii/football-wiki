## 每个页面有什么

- 真实照片（来自维基共享资源）
- 别名 / 外号（如 C罗的「总裁、CR7、小小罗」，贝克汉姆的「小贝、碧咸」……）
- 生平介绍（早年、俱乐部生涯、国家队生涯、荣誉等，取自维基百科条目）
- 信息框：全名、出生日期、出生地点、国籍、身高、位置、现效力俱乐部、球衣号码

## 站点结构

```
.
├── index.html          # 首页（球员卡片墙 + 筛选）
├── all.html            # 全部球员名录（可搜索/筛选）
├── about.html          # 关于本站
├── players/<id>.html   # 每位球员的页面 ×59
└── assets/             # 样式、脚本、照片
```

技术：纯 HTML + CSS + 原生 JavaScript，零前端依赖，静态托管于 GitHub Pages。

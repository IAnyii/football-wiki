关于足球百科

这是一个仿照 萌娘百科 排版风格的球员百科，收录了 59 位足球运动员的人物页面。网站是纯静态页面，托管在 GitHub Pages 上。

内容从哪里来？

  • 生平经历：取自中文维基百科对应条目的“生平 / 生涯”等章节，经繁简转换和排版整理；
  • 别名、外号：来自维基百科信息框的“昵称”字段与 Wikidata 别名；
  • 照片：来自维基共享资源（Wikimedia Commons，CC BY-SA 等自由协议）；
  • 出生日期、国籍、位置、俱乐部：来自维基百科信息框与 Wikidata 结构化数据。

所有资料均整理自上述公开来源，没有编造内容；如发现错误，欢迎在 GitHub 仓库提 Issue。

技术

纯 HTML + CSS + 原生 JavaScript（约 0 依赖），由 Node.js 脚本从维基百科 API 抓取数据后静态生成。
